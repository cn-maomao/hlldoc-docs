## 每个人都可以参与

注册账号并验证邮箱后，你可以提交新文档、修改建议、评论或错误反馈。所有公开内容都经过审核。

## 四级权限

| 权限 | 可执行操作 |
| --- | --- |
| 支持者 | 提交文档、修订、评论与错误反馈 |
| 贡献者 | 支持者全部能力；身份体现持续贡献 |
| 高级贡献者 | 审核其他用户的提交，维护内容质量 |
| 拥有者 | 审核、管理用户角色与账号状态 |

高级贡献者和拥有者也不能审核自己的提交。邮箱未验证的账号可以阅读与保存个人草稿，不能提交内容。

## 一次好的修订

说明修改原因，标注适用游戏版本，并附上可靠来源。将长篇内容分为清晰的小节，避免复制未经授权的作品。

## 审核与历史

提交进入审核队列；通过后公开，拒绝时可以查看原因。文档修订不会覆盖当前公开版本，审核通过才会替换。系统保留版本记录，并检测过期版本的冲突。

## 发现错误

在文档页选择“反馈错误”，说明原内容、建议修改和依据。你的反馈可以帮助编辑定位和修复问题。

> 本手册为社区原创入门内容。机制可能随游戏版本变化，请结合当前游戏内说明核对；欢迎附上版本和来源提交修订。
