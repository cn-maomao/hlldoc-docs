## 选择服务器

查看延迟、人数、语言和服务器说明。服务器名称不是全部信息，进入后阅读规则。

## 排队与重连

满员服务器可能需要排队。遇到断线先检查网络，避免反复快速点击连接。

## 遵守社区规则

不要故意攻击友军、滥用语音或破坏团队装备。争议应通过服务器提供的渠道反馈。

## 游戏外安全

不要向陌生人提供账号密码和登录验证码。服务器管理员不需要你的 Steam 密码。

> 本手册为社区原创入门内容。机制可能随游戏版本变化，请结合当前游戏内说明核对；欢迎附上版本和来源提交修订。
