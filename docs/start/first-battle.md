## 欢迎来到人间地狱

《人间地狱》（Hell Let Loose）是一款强调沟通与协作的二战多人战术射击游戏。你将成为一个小队的一员，参与大规模战场上的进攻与防守。

在这里，**生存、沟通和完成小队目标**，往往比击杀数更有价值。

## 开始前的准备

- 在设置中检查麦克风和语音输入设备。
- 选择延迟较低、规则清楚的服务器，先阅读服务器说明。
- 第一次游戏推荐加入已有步兵小队，选择步枪兵。
- 入队后告诉队长：“我是新兵，有什么需要我做的？”

## 选择出生点

打开部署界面，查看总部、驻军和小队前哨。优先选择队长指定的出生点，不要只看哪个离敌人最近。

出生后先看地图，确认当前目标和友军位置，再与小队汇合。

## 跟随小队行动

1. 使用掩体移动，避免长时间穿过开阔地。
2. 观察后再开火；枪声和枪口火光会暴露你的位置。
3. 报点时说明**方向、距离、地标和目标类型**。
4. 进攻受阻时告诉队长，尝试绕行或等待支援。

## 倒下以后

若附近有安全的救援机会，可以等待医疗兵；若位置已经暴露或队长要求重新部署，应及时调整。重新部署前检查地图，小队的任务可能已经改变。

## 新兵检查清单

- 我能听见小队语音，也能正常说话。
- 我知道目前在进攻还是防守哪个据点。
- 我跟随小队，没有独自跑向远离目标的区域。
- 我会简短、准确地报告敌情。
