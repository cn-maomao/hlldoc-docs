## 先读目标

进入对局后查看模式、剩余时间和当前可争夺据点。不同模式的进攻方向和胜利条件不同。

## Warfare：攻防并行

双方围绕战线上的据点进行攻防。拿下新据点后，仍需要安排防守、补充出生点和维持后勤。

## Offensive：逐线推进

进攻方需要在时限内推进，防守方需要守住目标。不要将其他模式的习惯直接套用。

## 防守同样重要

观察出生点预警、侧翼和敌方绕行路线。让小队留在有效目标区域，并与指挥官保持沟通。
